# Security policy

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability or include private
keys, tokens, application data, or signing material in a report.

Use GitHub private vulnerability reporting:

https://github.com/exolithelabs/exolithelabs-flatpak-repo/security/advisories/new

Include the affected workflow or published repository path, reproduction steps,
and expected impact. Never attach the Flatpak signing private key.

Security fixes are provided on the latest published repository state.
